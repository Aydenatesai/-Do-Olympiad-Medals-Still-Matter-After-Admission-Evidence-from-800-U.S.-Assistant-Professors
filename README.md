# -Do-Olympiad-Medals-Still-Matter-After-Admission-Evidence-from-800-U.S.-Assistant-Professors
Do Olympiad medals still matter after admission? Supervised by Prof. Thao Vuong. Scraped 800+ assistant professor profiles at Top 50 U.S. universities, identified ~40 former Olympiad medallists, and regressed research impact on medal status, controlling for college ranking.
